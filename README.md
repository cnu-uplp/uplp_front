# UPLP SWIM — 충남대 수영동아리 우파루파

충남대학교 수영동아리 **우파루파(UPLP)** 공식 웹사이트 프론트엔드입니다.
[Next.js](https://nextjs.org)(App Router) + TypeScript + Tailwind CSS v4로 만들었습니다.

백엔드는 별도 FastAPI 서버(`uplp_back`)입니다.

> ⚠️ **이 저장소는 공개되어 있습니다.**
> 실제 키·비밀번호·회원 개인정보(실명·전화번호·카카오 id)를 코드나 문서에 적지 마세요.
> 전부 환경변수로만 주입합니다. API 상세 명세는 Notion(비공개)에서 관리합니다.

## 주요 기능

### 정기수영 신청

실제 티켓팅처럼 동작합니다.

- **오픈 예약** — 관리자가 신청 시작·마감 시각을 미리 잡아둡니다. 오픈 전에는 신청 버튼이 계속 보이되 비활성 상태이고, 버튼 안에서 남은 시간이 실시간으로 줄어듭니다.
- **훈련부 / 진도부** 두 개 부서를 각각 별도 정원으로 받습니다.
- **선착순 배정** — 정원을 넘은 신청자는 **예비번호**를 받습니다.
- **취소 시 자동 당김** — 앞사람이 취소하면 예비 1번이 즉시 올라옵니다. 순번은 저장하지 않고 조회할 때마다 계산하므로 정원을 바꿔도 자동으로 다시 정렬됩니다.
- **후순위 제도** — 후순위로 지정된 회원은 별도 대기열에 쌓이고, 관리자가 병합해야 본 명단 뒤에 붙습니다. 병합 후에도 일반 신청자가 항상 앞섭니다.
- **인원 조정** — 신청을 받는 중에도 정원을 바꿀 수 있습니다. 줄이면 초과 인원이 대기로 내려가고, 늘리면 대기자가 자동으로 올라옵니다.
- **명단 대시보드** — 표 형태로 누가 들어갔는지 볼 수 있습니다(접기/펼치기). **실명은 승인된 회원에게만** 보이고 나머지는 `***`로 가려집니다.
- **연타 방지** — 정각에 버튼을 여러 번 눌러도 요청은 한 번만 나갑니다. 서버도 중복을 409로 막지만, 화면에 "이미 신청했습니다"가 떠서 성공한 신청을 실패로 오해하는 일을 없앴습니다.
- **관리자 도구** — 수정하기(오픈 전까지만) · 인원 조정 · 마감하기 · 후순위 병합 · 명단 다운로드 · 삭제하기(확인 팝업).

### 레인대관 신청서 자동 생성

정기수영이 마감되면 시설 제출용 신청서(원본 HWP 양식)를 `.docx`로 재현해 내려받습니다.

- 원본 양식의 좌표·글자 크기·행 높이·테두리 굵기를 실측해 **A4 3페이지를 1mm 이내로 재현**합니다.
- 자동으로 채워지는 값: 참석자 이름 / 전화번호 / 사용 희망 날짜 / 이용 인원
- 명단에는 **배정 인원만** 들어갑니다(예비·후순위 대기 제외).
- **신청 마감 후**에만, **관리자만** 받을 수 있습니다.
- 동아리 정보(단체명·서명인·연락처·이용시간)는 백엔드 환경변수로 관리합니다.

> 생성된 신청서에는 **회원 실명과 전화번호가 들어갑니다.**
> 저장소나 공유 드라이브에 올리지 말고, 제출 후에는 로컬에서 지워 주세요.

### 공지 · 일정

- 임원진이 공지와 일정을 쓰고, 고정(📌)해서 맨 위에 둘 수 있습니다.
- **이미지 첨부** — 한 장, 5MB 이하. 파일을 고르면 즉시 업로드되고 미리보기가 뜹니다.
- **댓글** — 글은 임원진만 쓰지만 댓글은 승인된 회원 누구나 씁니다. 본인 댓글은 본인이, 임원진은 남의 것도 지울 수 있습니다.

### 홈 · 동아리 소개 편집

문구가 코드에 박혀 있으면 회비·활동 시간이 바뀔 때마다 배포를 해야 해서, 임원진이 화면에서 직접 고치도록 했습니다.

- **자유 섹션(마크다운)** — 추가·수정·삭제·순서 변경. 가로 크기를 `한 줄 전체 / 1/2 / 1/3` 중에 고릅니다(1/2 넷을 만들면 2×2). 편집 중 미리보기가 함께 뜹니다.
- **동아리 기본 정보** — 활동 시간·장소·대상·회비. **홈 히어로와 소개 페이지가 같은 목록을 읽습니다.** 한 곳에서 고치면 양쪽이 같이 바뀝니다.
- 아직 아무것도 등록하지 않았으면 **코드에 있던 기존 화면이 그대로** 보이고, 임원진에게만 "기존 내용 가져와서 편집하기" 버튼이 뜹니다. 한 번 누르면 그 내용이 편집 가능한 섹션이 됩니다.
- 마크다운은 라이브러리 없이 안전한 부분집합만 렌더합니다. `dangerouslySetInnerHTML`을 쓰지 않고 React 엘리먼트로 조립하므로 본문에 `<script>`를 적어도 글자로만 보이고, 링크는 `http/https/mailto`만 허용합니다.

### 로그인 / 권한

- **카카오 로그인만** 지원합니다. **개인정보를 최소한만 보관하기 위해 자체 회원가입은 두지 않았습니다.**
- 최초 로그인 시 실명·학번(뒤 2자리)·전화번호·단과대·학과를 한 번 입력받습니다.
  **건너뛸 수 없습니다** — 정보를 넣지 않으면 어느 페이지로 가든 모달이 떠서 막습니다.
  이름·학번이 없으면 대관 명단에 `회원97` 같은 값이 찍히고, 임원진은 승인 판단을 할 근거가 없습니다.
- 권한은 세 축이 독립적으로 움직입니다.

| 축 | 값 | 의미 |
|---|---|---|
| 역할 | 일반 부원 / 임원진 / 관리자 | 임원진은 운영 기능, 관리자는 거기에 역할 변경까지 |
| 소속 | 재학생 / 졸업생 / 외부인 | **정기수영 신청은 재학생만** |
| 가입 승인 | 대기 / 승인 / 거절 | 승인 전에는 둘러보기만 |
| 직위 | `회장` 등 자유 입력 | 표시 전용 — 권한과 무관 |

프론트에서 UI를 숨기는 동시에 서버에서도 다시 검사하므로, 개발자 도구로 우회해도 차단됩니다.

## 시작하기

### 1. 설치

```bash
npm install
```

### 2. 환경 변수 설정

`.env.example`을 복사해서 `.env.local`을 만들고 값을 채워주세요.
**`.env.local`은 커밋하지 않습니다.**

```bash
cp .env.example .env.local
```

| 변수명 | 설명 |
|---|---|
| `NEXT_PUBLIC_API_URL` | 백엔드 서버 주소 |

- 로컬 백엔드를 띄워 개발할 때 → `http://localhost:8000`
- 로컬 화면으로 운영 데이터를 볼 때 → 배포된 백엔드 주소 (**실제 데이터가 바뀌니 읽기 위주로만**)

> `NEXT_PUBLIC_` 접두사가 붙은 값은 **브라우저 번들에 그대로 노출됩니다.**
> 비밀 값은 절대 이 접두사로 두지 마세요. 백엔드 환경변수로만 다룹니다.
> 빌드 시점에 번들에 박히므로 **값만 바꾸고 재배포하지 않으면 반영되지 않습니다.**

백엔드에 필요한 환경변수는 `uplp_back/README.md`를 참고하세요.

> 카카오 개발자 콘솔에 **Redirect URI**를 등록해야 합니다 (배포 주소와 로컬 주소 각각 `/login/kakao/callback`).
> 동의 항목은 콘솔에서 관리하므로 코드에서 `scope`를 넘기지 않습니다.

### 3. 개발 서버 실행

```bash
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

### 로그인이 필요한 화면을 보려면

카카오 로그인을 매번 태우기 번거로워서, 백엔드에 개발용 토큰 발급 스크립트를 두었습니다.
백엔드와 프론트를 한 번에 띄우고 토큰까지 출력하는 스크립트가 있습니다.

```bash
./dev.sh              # 관리자로 로그인
./dev.sh student      # 재학생 · executive · alumni · guest 도 가능
```

출력된 `localStorage.setItem(...)` 한 줄을 브라우저 콘솔에 붙여넣으면 그 계정으로 들어갑니다.
`Ctrl+C`를 누르면 백엔드까지 함께 정리됩니다.

## 모바일에서 겪었던 것들

`globals.css`에 좁은 화면 전용 규칙이 있습니다. 지우기 전에 이유를 확인하세요.

- **입력칸 글자 크기 16px** — iOS Safari는 16px 미만 입력칸을 누르면 화면을 자동 확대합니다.
  확대되면 레이아웃이 밀려 카드가 잘려 보이고 스크롤 위치도 튑니다.
- **스크롤 스냅 끔** — 휴대폰은 주소창이 접혔다 펴지고 키보드가 오르내리며 보이는 높이가
  계속 바뀝니다. 그때마다 `mandatory` 스냅이 가까운 섹션으로 다시 붙어 화면이 끌려갑니다.
  특히 입력 후 전송을 누르면 **포커스가 빠지는 순간** 점프했습니다. 데스크톱은 그대로 둡니다.
- **date 입력 `-webkit-appearance: none`** — iOS의 날짜 입력은 기본 렌더링이 고유 너비를
  들고 있어 `width:100%`를 줘도 줄지 않습니다.
- **모바일 드로어는 `document.body`로 portal** — 상단 `<header>`가 `fixed z-50`이라 자체
  쌓임 맥락을 만들고, 그 안에서는 `z-[61]`을 줘도 유리 카드 위로 못 올라갑니다.

## 배포

- 프론트: Vercel — `main` 브랜치 푸시 시 자동 배포
- 백엔드: AWS Lightsail (Ubuntu + Docker + nginx). 배포 절차는 `uplp_back/README.md` 참고

배포 환경변수는 각 호스팅 대시보드에서만 관리합니다. 저장소에 커밋하지 않습니다.

> 새 파일을 만들었으면 `git add`에 **반드시 포함**하세요. `git add -u`는 추적 중인 파일만
> 담아서, 새 컴포넌트가 빠지면 Vercel 빌드가 `Module not found`로 실패합니다.
